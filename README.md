# Inside the Algorithm — Week 05: Divide and Conquer

Interactive learning media for **INF203 — Desain dan Analisis Algoritma**.

This learning tool is designed to help students understand **Divide and Conquer** by observing how an algorithm works step by step before implementing it in code.

## Topics

- Divide, Conquer, and Combine
- Merge Sort
- Step-by-step algorithm trace
- Recursion and Base Case
- Binary Search
- Time Complexity
- Self-Check Questions

## Learning Approach

The activity follows the idea:

**Problem → Predict → Trace → Observe → Explain → Analyze → Apply**

Students do not begin by memorizing definitions. Instead, they observe each algorithmic decision and gradually identify the underlying strategy.

A key feature is the **Merge Sort micro-step trace**, where each interaction represents one algorithmic event:

**DIVIDE ↓ → BASE CASE → COMBINE ↑**

This helps students visualize how recursion moves toward the base case and how the solution is constructed when recursive calls return.
